# 📱 CrowdMonitor Mobile (Android App)

Native Android mobile application for **CrowdMonitor** (Smart Occupancy Intelligence Platform).

## 🚀 Download APK

The Android `.apk` package is automatically built on every release using GitHub Actions.

- Check the **[Releases](../../releases)** tab to download `app-debug.apk` directly to your phone.
- Tap the `.apk` file to install on your Android device (enable "Install unknown apps" if prompted).

## 🛠 Tech Stack
- **Framework**: Ionic Capacitor v6 (Android Native Bridge)
- **Frontend Core**: React 18 + TypeScript + Vite + Tailwind CSS
- **Target OS**: Android 7.0+ (API 24 to 35)
